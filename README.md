# To-Do Manager (Python)

A command-line based task management application developed using Python.
The application helps users organize daily tasks by allowing them to add, view, complete, and delete tasks efficiently. Task data is stored using JSON to maintain persistence between sessions.

---

## Features

* Add tasks with priority and due date
* View all existing tasks
* Mark tasks as completed
* Delete tasks from the list
* Store and retrieve task data using JSON
* Simple and structured command-line interface

---

## Technologies Used

* Python
* JSON for file-based data storage

---

## How to Run

1. Ensure Python is installed on your system
2. Clone or download this repository
3. Open terminal in the project directory
4. Run the following command:

```bash id="o0nls8"
python todo_app.py
```
